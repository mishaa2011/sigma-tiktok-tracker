# TikTok Weekly Tracker — стартовый проект

Это рабочая основа сайта: форма отправки ссылок, SQLite, защита входа администратора, запрет повторных ссылок, недельные периоды по московскому времени, панель с архивом, скрытие не прошедших норму по умолчанию и настройки сайта.

## Важно: чего пока нет
TikTok не предоставляет универсальный официальный API для автоматического получения статистики произвольного публичного видео по одной ссылке. В этом проекте **реальный сбор просмотров и ИИ-анализ не подключены**. Нельзя выдавать демонстрационный/ручной ввод статистики за автоматическую проверку. Для автоматизации нужно выбрать проверенного поставщика API и получить ключ; после этого подключается адаптер получения просмотров, лайков, комментариев и репостов. Проверка ИИ также требует явного подключения модели/сервиса и его ключа.

## Запуск на Windows
1. Установи Python 3.11 или новее.
2. Распакуй архив в папку.
3. Открой PowerShell в папке проекта.
4. Выполни:
   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
5. Задай секреты в PowerShell (замени значения на свои, не публикуй их):
   ```powershell
   $env:ADMIN_PASSWORD = "создай-новый-длинный-пароль"
   $env:SESSION_SECRET = "создай-длинную-случайную-строку-не-короче-32-символов"
   ```
6. Запусти:
   ```powershell
   uvicorn app:app --host 127.0.0.1 --port 8000
   ```
7. Открой `http://127.0.0.1:8000`.
8. Панель администратора: `http://127.0.0.1:8000/admin`.

## Настройка
В админ-панели → «Настройки» можно менять название, минимальные/максимальные просмотры, ставку, отображаемый адрес и временно выключать приём ссылок. Изменение поля домена само по себе не регистрирует и не подключает домен: для публикации нужны домен, DNS, HTTPS и сервер.

## Безопасность перед публикацией
- Пароль, который ранее был написан в переписке, считай раскрытым и **не используй его как пароль продакшена**. Задай новый через `ADMIN_PASSWORD`.
- Сгенерируй случайный `SESSION_SECRET` (минимум 32 символа).
- Для публичного сервера включи HTTPS, `https_only=True` в настройке сессий, защиту от перебора пароля и CSRF-защиту.
- Сделай резервное копирование `tracker.db`.
- Не собирай лишние персональные данные и опубликуй правила обработки данных.

## Правила подсчёта
- По умолчанию минимальная норма — 2 000 просмотров, максимальный лимит — 1 000 000.
- Выплата в панели рассчитывается пропорционально: просмотры / 1000 × ставка. Это предварительный расчёт, не платёж.
- Список по умолчанию показывает прошедшие норму видео и записи, помеченные для проверки. «Показать всех» раскрывает остальные записи.
- Неделя задаётся по `Europe/Moscow`; начало приёма — понедельник 00:00, окончание — следующий понедельник 00:00.

## Текущий статус
Можно запустить и проверить интерфейс и отправку ссылок локально. Автоматические данные TikTok, автоматический ИИ-анализ, публичный хостинг и реальная платёжная интеграция — следующие этапы, требующие выбора провайдера/сервера.
